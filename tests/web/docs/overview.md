# web-tests

The marketing site's and its packages' tests (the CMS sample content, the code highlighter, the rate limit on KV, the health check, the wrangler config), run on every pull request

The test suite for **web**. It deploys nothing: its lane installs, builds and runs the tests.

| ------------ | -------------------- |
| Type         | `turbo-package`      |
| Source       | `tests/web`          |
